# Screenshot provenance

The images are explicitly synthetic demonstrations, generated by
`python frontend/scripts/research_browser_check.py` from the temporary database
created by `frontend/scripts/export_research_fixtures.py`. No production database,
private configuration or operator record was used. Both were visually reviewed
and their PNG chunks checked for unexpected metadata before publication.

- `overview.png`: market overview with synthetic prices/activity and honest stale/insufficient states.
- `research-lab.png`: a synthetic experiment, exploratory change records and insufficient sequence support.

Fixture event times are historical; stale labels are expected. The header clock
is the capture clock, not an assertion that synthetic prices are current. The
synthetic display never establishes live market behavior or predictive performance.
The browser suite emits local screenshots under ignored `frontend/test-results/`;
only these reviewed copies are included in documentation.
